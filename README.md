# ANWURF! – Der Handball gehört dir

Von der Schulturnhalle zum Handballimperium: ein Handball-Manager im Retro-Stil, reines HTML/JavaScript.

**Spielen:** https://gijoehh.github.io/anwurf/

**Auf dem iPad installieren:** Die Adresse in Safari öffnen → Teilen → **Zum Home-Bildschirm**. Danach einmal über das Symbol starten. Ab dann läuft das Spiel auch ohne Internet.

Spielstände bleiben im Browser des Geräts, auf keinem Server wird etwas gespeichert.
Abgleich mit der Mac-App: *Speichern → ☁︎ In iCloud sichern* bzw. *Spielstand importieren*.

Diese Dateien werden automatisch aus dem privaten Projektordner erzeugt (`web/deploy.sh`). Änderungen bitte dort vornehmen.
